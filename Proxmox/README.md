# Proxmox

A guide for installing and configuring Proxmox Virtual Environment on old PC (ASUS TUF Gaming FX705, Windows 11).

First you will need to [download and install](Installation.md) Proxmox VE hypervisor.

You can change configuration later after initial setup anytime. For example if you need to change the IP of the management, you can do that in GUI or by [editing source files on the host](Networking.md#configuring-management-ip).
